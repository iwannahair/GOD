# 自动发射功能设置指南

## 功能概述
自动发射功能允许预制体无需按键即可连续发射，支持开关控制、频率调节和程序化控制。

## 快速启用步骤

### 1. 启用自动发射
在PlayerShooter组件中：
- 勾选**Auto Fire**复选框启用自动发射
- 勾选**Auto Fire On Start**游戏开始时自动发射

### 2. 设置发射频率
- **Fire Rate**：设置每秒发射次数（建议范围：0.5-10）
- 数值越小，发射间隔越长
- 数值越大，发射频率越高

### 3. 测试自动发射
1. 点击Play按钮
2. 观察是否自动开始发射
3. 调整Fire Rate观察频率变化

## 高级控制方法

### 方法1：通过脚本控制
```csharp
// 获取PlayerShooter组件
PlayerShooter shooter = GetComponent<PlayerShooter>();

// 启用自动发射
shooter.SetAutoFire(true);

// 禁用自动发射
shooter.SetAutoFire(false);

// 切换自动发射状态
shooter.ToggleAutoFire();

// 设置发射频率
shooter.SetFireRate(3f); // 每秒3次
```

### 方法2：通过UI按钮控制
创建UI按钮控制自动发射：

1. 创建UI按钮：
   - **Hierarchy** → **UI** → **Button**
   - 重命名为"AutoFireButton"

2. 设置按钮事件：
   - 选择按钮
   - 在**Button**组件的**OnClick()**中添加玩家对象
   - 选择**PlayerShooter** → **ToggleAutoFire()**

### 方法3：通过条件触发
```csharp
// 示例：当敌人靠近时自动发射
void Update()
{
    if (IsEnemyNearby())
    {
        GetComponent<PlayerShooter>().SetAutoFire(true);
    }
    else
    {
        GetComponent<PlayerShooter>().SetAutoFire(false);
    }
}
```

    GetComponent<PlayerShooter>().SetAutoFire(true);

### 场景3：渐进式发射
```csharp
// 随时间增加发射频率
float elapsedTime = 0f;

void Update()
{
    elapsedTime += Time.deltaTime;
    float newRate = 1f + (elapsedTime / 10f); // 每秒增加0.1
    GetComponent<PlayerShooter>().SetFireRate(Mathf.Min(newRate, 10f));
}
```

## 性能优化

### 限制最大频率
```csharp
// 在SetFireRate方法中已内置限制
public void SetFireRate(float rate)
{
    fireRate = Mathf.Max(0.1f, rate); // 最小间隔0.1秒
    fireRate = Mathf.Min(10f, rate);  // 最大频率10次/秒
}
```

### 使用对象池
对于高频发射，建议使用对象池：
```csharp
// 在Projectile脚本中添加自动回收
public class Projectile : MonoBehaviour
{
    public float lifeTime = 3f;
    
    void OnEnable()
    {
        Invoke("Disable", lifeTime);
    }
    
    void Disable()
    {
        gameObject.SetActive(false);
    }
}
```

## 常见问题解决

### Q：自动发射不工作？
**检查**：
1. 确认Auto Fire已勾选
2. 检查Fire Rate是否大于0
3. 确认预制体已正确设置
4. 检查是否有其他脚本禁用了发射

### Q：发射频率过快导致性能问题？
**解决**：
1. 降低Fire Rate值
2. 使用对象池管理实例
3. 添加最大频率限制

### Q：如何暂停自动发射？
**方法**：
```csharp
// 暂停
GetComponent<PlayerShooter>().SetAutoFire(false);

// 恢复
GetComponent<PlayerShooter>().SetAutoFire(true);
```
