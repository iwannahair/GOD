# Unity 2D玩家移动设置指南

## 方法1：使用Unity内置组件（推荐）

### 步骤1：设置玩家对象
1. **创建玩家对象**：
   - 将玩家图片拖入Hierarchy
   - 重命名为"Player"
   - 添加**Rigidbody 2D**组件
   - 设置**Body Type**为**Kinematic**

2. **添加碰撞器**：
   - 添加**Box Collider 2D**或**Circle Collider 2D**
   - 调整碰撞器大小匹配图片

### 步骤2：使用Unity输入系统
1. **打开输入设置**：
   - Edit > Project Settings > Input Manager
   - 确认Horizontal和Vertical轴已设置（默认已包含WASD）

2. **添加脚本组件**：
   - 添加**SimplePlayerMovement**脚本
   - 调整speed参数（如：5）
   - 调整boundaryPadding参数（如：0.5）

### 步骤3：设置相机边界
1. **确保主相机设置**：
   - Projection设置为**Orthographic**
   - Size调整合适的视角大小

## 方法2：完全无代码方案（使用Bolt/Visual Scripting）

### 步骤1：安装Visual Scripting
1. **Package Manager**：
   - Window > Package Manager
   - 搜索"Visual Scripting"
   - 点击安装

### 步骤2：创建视觉脚本
1. **创建Script Graph**：
   - 右键Assets > Create > Bolt > Flow Macro
   - 命名为"PlayerMovement"
   - 拖入Player对象

### 步骤3：设置节点逻辑
1. **基本移动节点**：
   - On Update事件
   - Get Axis节点（Horizontal和Vertical）
   - Translate节点
   - Clamp Position节点（限制边界）

## 方法3：使用物理约束（最简单）

### 步骤1：设置物理边界
1. **创建边界**：
   - 创建4个空GameObject作为边界墙
   - 添加**Box Collider 2D**组件
   - 放置在相机边缘

### 步骤2：玩家设置
1. **玩家配置**：
   - Rigidbody 2D（Body Type: Dynamic）
   - 添加**Box Collider 2D**
   - 添加**PlayerMovement**脚本

## 常见问题解决

### 问题1：玩家移动过快/过慢
**解决方案**：调整脚本中的speed参数

### 问题2：玩家可以移出屏幕
**解决方案**：检查boundaryPadding值，确保相机正确定位

### 问题3：对角线移动过快
**解决方案**：脚本已包含归一化处理，确保对角线速度一致

## 推荐设置

### 玩家对象组件
- **Transform**：位置(0,0,0)
- **Sprite Renderer**：玩家图片
- **Rigidbody 2D**：Body Type = Kinematic
- **Box Collider 2D**：匹配图片大小
- **SimplePlayerMovement**脚本

### 相机设置
- **Projection**：Orthographic
- **Size**：5（根据需求调整）
- **Position**：(0,0,-10)
