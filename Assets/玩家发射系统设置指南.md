# 玩家发射系统设置指南

## 功能说明
从玩家头顶的发射点实例化预制体，支持按键发射和自动瞄准功能。

## 快速设置步骤

### 1. 添加PlayerShooter脚本
1. 在Hierarchy中选择玩家对象
2. 点击**Add Component** → **Scripts** → **PlayerShooter**

### 2. 创建发射预制体
#### 方法一：使用现成预制体
1. 在Assets/Prefabs文件夹创建新文件夹"Projectiles"
2. 创建简单的圆形或方形Sprite
3. 添加必要组件：
   - **Rigidbody2D**
   - **Collider2D**（BoxCollider2D或CircleCollider2D）
   - **Projectile**脚本（可选）

#### 方法二：手动创建
1. **Hierarchy** → **2D Object** → **Sprite** → **Circle**
2. 重命名为"Projectile"
3. 添加组件：
   - **Rigidbody2D**：Body Type设为Dynamic，Gravity Scale设为0
   - **CircleCollider2D**：设置合适半径
4. 设置SpriteRenderer：
   - Color设为亮黄色
   - Sorting Order设为5
5. 保存为预制体：拖拽到Assets/Prefabs文件夹

### 3. 配置发射系统
在PlayerShooter组件中设置：
- **Projectile Prefab**：拖拽创建的预制体到该字段
- **Fire Rate**：发射频率（默认1次/秒）
- **Fire Key**：发射按键（默认空格键）
- **Fire Offset**：发射点偏移（默认头顶0.5单位）

### 4. 测试发射
1. 点击Play按钮
2. 按空格键发射
3. 观察：
   - 黄色小圆点从玩家头顶发射
   - 发射方向为向上
   - 发射频率受限制

## 高级功能设置

### 自动发射功能
修改PlayerShooter.cs，添加自动发射：
```csharp
[Header("自动发射")]
public bool autoFire = false;        // 是否自动发射
public float autoFireDelay = 0.5f;   // 自动发射延迟

void Update()
{
    if (autoFire && Time.time >= nextFireTime)
    {
        Fire();
        nextFireTime = Time.time + autoFireDelay;
    }
    else if (Input.GetKeyDown(fireKey) && Time.time >= nextFireTime)
    {
        Fire();
        nextFireTime = Time.time + 1f / fireRate;
    }
    
    UpdateFirePointPosition();
}
```

### 瞄准鼠标方向发射
添加鼠标瞄准功能：
```csharp
void Fire()
{
    if (projectilePrefab != null && firePoint != null)
    {
        GameObject projectile = Instantiate(projectilePrefab, firePoint.position, Quaternion.identity);
        
        // 计算鼠标方向
        Vector3 mousePos = Camera.main.ScreenToWorldPoint(Input.mousePosition);
        Vector2 direction = (mousePos - firePoint.position).normalized;
        
        Rigidbody2D rb = projectile.GetComponent<Rigidbody2D>();
        if (rb != null)
        {
            rb.velocity = direction * 5f;
        }
    }
}
```

## 常见问题解决

### 预制体不显示
- 检查SpriteRenderer是否启用
- 确认Sorting Order设置正确
- 检查预制体是否在摄像机视野内

### 发射方向错误
- 确认Rigidbody2D的Gravity Scale为0
- 检查发射方向向量是否正确
- 验证Collider2D设置

### 发射频率异常
- 检查Fire Rate数值是否合理
- 确认Update方法中的时间计算正确
- 验证按键检测逻辑

### 发射点位置错误
- 调整Fire Offset数值
- 确认发射点父物体设置正确
- 检查坐标系转换

## 性能优化建议

### 对象池管理
创建简单的对象池：
```csharp
using System.Collections.Generic;

public class ProjectilePool : MonoBehaviour
{
    public GameObject projectilePrefab;
    public int poolSize = 10;
    private Queue<GameObject> pool = new Queue<GameObject>();
    
    void Start()
    {
        for (int i = 0; i < poolSize; i++)
        {
            GameObject obj = Instantiate(projectilePrefab);
            obj.SetActive(false);
            pool.Enqueue(obj);
        }
    }
    
    public GameObject GetProjectile()
    {
        if (pool.Count > 0)
        {
            GameObject obj = pool.Dequeue();
            obj.SetActive(true);
            return obj;
        }
        return Instantiate(projectilePrefab);
    }
    
    public void ReturnProjectile(GameObject obj)
    {
        obj.SetActive(false);
        pool.Enqueue(obj);
    }
}
```
