# 玩家组合系统设置指南

## 功能说明
这个系统创建一个始终跟随玩家的物体，并确保玩家和跟随物体组成的整体无法离开摄像机显示范围。

## 快速设置步骤

### 1. 添加PlayerGroupController脚本
1. 在Hierarchy中选择玩家对象
2. 点击**Add Component** → **Scripts** → **PlayerGroupController**

### 2. 配置跟随物体
有两种方式设置跟随物体：

#### 方式一：自动创建（推荐）
- 无需额外设置，脚本会自动创建一个红色方块作为跟随物体
- 跟随物体会自动定位在玩家下方1个单位处

#### 方式二：使用现有物体
1. 创建一个新的GameObject作为跟随物体
2. 在Inspector中将该物体拖拽到PlayerGroupController的**Follow Object**字段
3. 调整**Follow Offset**设置偏移量（默认为(0, -1)）

### 3. 调整边界设置
- **Padding**：边界内边距，防止物体贴边（默认0.5）

## 测试验证

### 1. 运行测试
1. 点击Play按钮
2. 使用WASD键移动玩家
3. 观察：
   - 红色方块是否始终跟随在玩家下方
   - 玩家是否能被限制在屏幕范围内

### 2. 边界测试
尝试将玩家移动到屏幕边缘，确认：
- 玩家无法超出屏幕边界
- 跟随物体始终保持在相对位置

## 自定义设置

### 修改跟随物体外观
1. 在Hierarchy中找到自动创建的"FollowObject"
2. 修改SpriteRenderer组件：
   - 更换Sprite
   - 调整颜色
   - 修改大小

### 调整跟随位置
在PlayerGroupController组件中：
- 修改**Follow Offset**改变相对位置
- 例如设置为(0, -2)让物体在玩家下方2个单位

## 常见问题解决

### 跟随物体不可见
- 检查Sorting Order是否设置正确（默认-1，在玩家下方）
- 确认SpriteRenderer已启用
- 检查颜色透明度

### 边界限制不准确
- 确保摄像机已正确设置为Main Camera
- 检查Padding值是否合适
- 确认玩家对象的Collider或Renderer尺寸正确

### 跟随物体延迟
- 这是正常现象，因为位置更新在Update中
- 如需更精确的控制，可以调整脚本中的更新时机

## 进阶使用

### 动态更换跟随物体
```csharp
// 通过代码更换跟随物体
PlayerGroupController controller = GetComponent<PlayerGroupController>();
controller.SetFollowObject(newFollowObject);
```

### 设置不同偏移
```csharp
// 设置跟随偏移
controller.SetFollowOffset(new Vector2(1, -1)); // 右下方
```

## 无需代码的替代方案

如果不想使用脚本，可以使用以下方法：

### 1. 父子物体关系
1. 创建空GameObject命名为"PlayerGroup"
2. 将玩家和跟随物体都作为子物体
3. 设置跟随物体的相对位置为(0, -1, 0)
4. 使用之前创建的SimplePlayerMovement脚本限制移动范围

### 2. 使用Unity动画系统
1. 创建Animator Controller
2. 设置跟随物体的位置动画
3. 使用脚本激活相应的动画状态

## 性能优化

- 跟随物体的Sprite使用小尺寸纹理
- 避免在Update中频繁计算边界（已优化）
- 使用对象池管理跟随物体（如需动态创建）
